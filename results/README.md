# Results

Metrics CSVs and figures produced by evaluation and analysis are written here.

**These outputs are gitignored** with two exceptions that are committed as the reportable
record of the experiments:

- `summary_table.csv` – the final cross-model comparison table (DSC, IoU, HD95, pixel
  accuracy as mean ± std for UNet, TransUNet, and Swin-UNet).
- Figures explicitly added for the thesis, when finalised.

Everything else (per-image result CSVs, checkpoints, scratch figures, Grad-CAM dumps) stays
local only.
